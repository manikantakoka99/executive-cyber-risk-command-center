# Delivery Plan — Client Engagement

## Positioning one-liner

> One command view that turns every YVI security use case into a board-ready business risk narrative — in minutes, not days.

## Engagement phases

### Phase 0 — Discovery (1 week)
- Inventory upstream YVI modules and data readiness
- Confirm frameworks, appetite, board cadence
- Baseline: hours spent on last 2 board packs
- **Exit:** signed MVP backlog + demo success criteria

### Phase 1 — MVP build (6 weeks)
See `PRD.md` M1–M5. Weekly demos to client sponsor.

### Phase 2 — Pilot (6 weeks)
- Wire 3–5 live feeds
- Run one real board cycle with dual-track (old pack vs YVI pack)
- Measure time-to-insight and edit distance
- **Exit:** go/no-go for productize + retainer quote

### Phase 3 — Productize
- Multi-tenant MSSP mode
- FAIR-lite scenarios
- PPTX export + white-label

## Workshop agenda (90 min)

| Time | Topic |
|------|-------|
| 0–10 | Pain playback (many dashboards, no business view) |
| 10–25 | Live demo of Command Center |
| 25–45 | Map their use cases → domain feeds |
| 45–65 | Narrative walkthrough + edit exercise |
| 65–80 | Commercial: license + managed insight retainer |
| 80–90 | Next steps & pilot scope |

## Risks & mitigations

| Risk | Mitigation |
|------|------------|
| Upstream data immature | Ship strong demo dataset; score freshness explicitly |
| Board distrust of AI narrative | Human edit required; facts-only LLM; evidence links |
| Scope creep into full GRC/CRQ | PRD non-goals; phase gates |
| Competing Diligent/SAFE bake-off | Emphasize YVI suite feed advantage + MSSP retainer |
